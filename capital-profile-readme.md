# Личный капитал: демонстрационный профиль

Отдельный пример по публичному видео технического задания. Не клиентская платформа, не коммерческий кейс и не полный спринт 1. Исходный HTML заказчика не получен; внешний вид восстановлен по видео.

## Две версии
- capital-profile.html — интерактивный просмотр Vue на GitHub Pages. Данные сохраняются только в localStorage текущего браузера. Здесь нет серверной проверки, авторизации или почты.
- capital-profile-source.zip — исходники серверной версии: Laravel 13, Vue 3, Inertia 3, SQLite для локальной проверки. Профиль сохраняется на сервере, данные изолированы по сессии; FormRequest проверяет email, дату рождения, суммы и допустимые цели.

Показаны контакты и семья, 6 примеров целей из списка, сумма целей, процент заполнения 6 блоков, ситуация, стратегия и шкала активного возраста. Правило процента заполнения — демонстрационное, подлежит сверке с исходниками. Рабочий дашборд, формулы доходности, фото, рефералы, роли и админка в пример не входят.

## Запуск серверной версии
Нужны PHP 8.3+, Composer и Node.js 22+ (для сборки Vite).
1. Распаковать архив в пустую папку.
2. Выполнить composer install и npm ci.
3. Скопировать .env.example в .env. Указать локальный APP_URL, DB_CONNECTION=sqlite, SESSION_DRIVER=file.
4. Создать пустой database/database.sqlite.
5. Выполнить php artisan key:generate, php artisan migrate, npm run build.
6. Выполнить php artisan serve.

## Проверки
php artisan test --compact tests/Feature/DemoProfileTest.php
4 теста / 31 проверка: сохранение и повторное открытие, отклонение неверного email/даты/суммы, изоляция профилей, неизвестные и повторные цели.
В браузере проверены ошибочный email, изменение города и суммы, сохранение после обновления страницы, меню и ширина 390 px. Демо не предназначено для ввода реальных персональных и финансовых данных или размещения в production без полноценной авторизации.

В архив не включены .env, базы данных, серверные сессии, vendor и node_modules.
