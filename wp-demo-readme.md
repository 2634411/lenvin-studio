# Lenvin — WordPress demo leads

Новый демонстрационный проект, не клиентский кейс. WordPress и собственный PHP-плагин. Без Битрикс24, писем и платежей.

Запуск: откройте wp-demo.html и нажмите кнопку Playground. Blueprint создает отдельную WordPress-среду в браузере и входит как тестовый администратор. Доступы к реальным сайтам не используются. Только вымышленные данные.

Проверено 29.10.2026 на WordPress 7.1.4 / PHP 8.3 через официальный Playground CLI:
- Форма отправляет запрос REST; запись с именем и телефоном появляется в админке.
- Повторная отправка без изменения полей возвращает прежний ID.
- Некорректный телефон отклоняется интерфейсом.

Ограничения: endpoint требует manage_options и REST nonce. Transient устраняет обычную последовательную повторную отправку, но не является транзакционной защитой от конкурентных запросов. Мобильные стили предусмотрены, визуальная мобильная проверка еще не выполнена. Это не готовая production-интеграция.

lenvin-leads.php — GPL-2.0-or-later; wp-demo-plugin.zip — установочный архив; wp-demo-blueprint.json — воспроизводимая настройка. Скриншоты сняты в настоящей локальной WordPress-среде.
