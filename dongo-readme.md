# DON-GO - интерактивная концепция

Демонстрация: https://2634411.github.io/lenvin-studio/dongo-demo.html

Индивидуальный дизайн региональной площадки: главная, поиск и каталог, карточка товара, страница магазина, кабинеты продавца и модератора.

Можно создать объявление, отправить на проверку, одобрить и увидеть его в каталоге. Работают текстовый поиск, категории, выбор города, сортировка и избранное.

Версия GitHub Pages сохраняет объявления и избранное только в браузере посетителя (localStorage). Данные не передаются другим посетителям и не хранятся на сервере. Пример не является запущенным маркетплейсом, клиентским кейсом или защищенной системой авторизации. Переключение кабинетов открыто для показа сценария. Не вводите реальные личные данные.

Товары, цены, магазины и фотографии в примере иллюстративные. Подключение реальных аккаунтов, загрузки изображений, сообщений, жалоб, продвижения, тарифов, подписок, оплаты и внешних интеграций в эту демонстрацию не входит.

Файл автономный: изображения, шрифты, стили и сценарии встроены. Никаких ключей доступа или баз данных в публикации нет. Для полной платформы необходима отдельная серверная разработка.
