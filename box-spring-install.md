# Box Spring — WordPress

Тестовая версия: https://boxspring.ros-style.ru/

Архив `box-spring-theme.zip` содержит исходники отдельной блочной темы Hotel Bed Box Spring. WordPress работает на REG.RU; GitHub хранит исходники, а не исполняет WordPress. Пароли, конфигурация базы данных и дампы в репозиторий не включены.

## Редактирование

Админка: https://boxspring.ros-style.ru/wp-admin/

1. Откройте «Страницы» → «Кровати Box Spring для отелей».
2. Нажмите на текст и отредактируйте его; затем «Сохранить».
3. Чтобы заменить фото, выделите его → «Заменить» → «Загрузить» или «Медиатека».
4. Чтобы добавить кровать, выделите группу карточки целиком (через обзор документа или кнопку выбора родительского блока), откройте меню с тремя точками → «Дублировать». Замените фото и текст новой карточки, затем сохраните.
5. Меню и подвал доступны через «Внешний вид» → «Редактор» → «Части шаблона».

Копирование карточки проверено в работающем WordPress: на первоначальной версии макета. Изменение и сохранение текста проверено на опубликованной странице. Фотографии перенесены в медиатеку; три схемы доступны из папки темы.

## Установка на другой сайт

Сделайте резервную копию сайта назначения. Установите тему через «Внешний вид» → «Темы» → «Добавить» → «Загрузить тему». После активации используйте «Внешний вид» → «Настройка Box Spring» → «Создать или открыть черновик». Это создает новую страницу и не заменяет существующие. После проверки опубликуйте ее и выберите статической главной в «Настройки» → «Чтение».

Для переноса именно отредактированной тестовой версии нужно перенести ее базу данных, медиатеку и тему, затем корректно заменить тестовый домен на домен заказчика с учетом сериализованных данных WordPress. Один архив темы не содержит последующие изменения страницы в базе.

## Еще согласовать перед сдачей

- Состав слоев и толщину фанеры; обе схемы пока условные.
- Подписи «до/после»; сейчас подписи нейтральные.
- Настоящую ссылку профиля MAX; номер получен, переход по вымышленной ссылке не используется.
- Нужна ли форма и адрес получателя. Форма подготовлена, но скрыта до настройки адреса получателя и ссылки на политику; доставку писем нужно проверить после подключения.
- После переноса проверить HTTPS, версию PHP, медиатеку, адаптивность, ссылки и фактическую доставку заявок, если форма будет согласована.

На тестовом сайте включен запрос поисковым системам не индексировать его. Это не ограничивает доступ по прямой ссылке.

## Галереи — версия 1.3.0

Четыре галереи построены на стандартном блоке WordPress «Галерея». Кнопки и счетчик создаются на сайте автоматически. Платных расширений нет.

1. Откройте главную страницу и выберите нужную фотографию.
2. В нижней цепочке блоков нажмите «Галерея».
3. В боковой панели «В виде списка» нажмите «Добавить изображение».
4. У пустого изображения откройте «Добавить изображение» → «Открыть библиотеку файлов» либо «Загрузить».
5. Выберите фотографию и нажмите «Сохранить». Счетчик и кнопки подстроятся автоматически.

Для удаления выделите изображение и используйте меню блока. Для смены порядка используйте стрелки перемещения. Галерею можно дублировать целиком; сохраняйте родительскую группу с CSS-классом bs-carousel. В разделе паттернов есть «Фотогалерея с переключением».

Проверено на опубликованной странице: добавление изображения через медиатеку увеличило галерею с 3 до 4 фотографий; затем тестовый дубль удален, снова 3. Перелистывание проверено на компьютере и при ширине 360 px. В итоговой версии четыре галереи: 3 / 4 / 6 / 4 фотографий.

Из QR-кода получена прямая ссылка MAX, сохранена в настройках контактов. Проверен профиль «Евгений Сайгин». Отдельная форма заявки заказчику не нужна, на странице ее нет. После согласования переносить на hotelbed.ru; тестовый адрес пока не менять.
